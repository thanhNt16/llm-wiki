  - `jev.ask(state: str, questions: dict) -> dict` → `{"ok": bool, "answers": {q: {"type": t, "value": v}}, "usage": dict, "disabled": bool, "error": str|None}`; normalizes wire `noul` → `{"type":"noul","value":<float p_yes>}`, `choice` → `{"type":"choice","value":{"pick": str, "distribution": {opt: p}}}`, `score` → `{"type":"score","value":{"level": int, "expected": float}}`; timeout 10s; `disabled:true` + `ok:false` when env unset.
  - CLI `wiki.py jev`: `--check` prints `{"ready": bool, "model"|"reason"}` exit 0 always; `--state S --question <json>` prints `ask` result.
  - `page-targets --decide`: for each target where `matched_rule` starts with `"heuristic:"`, call `ask` with one `choice` question over `["concepts","entities","procedures","questions"]` and attach `"decision": {"suggested_kind": pick, "confidence": <p>}` to the target; env off → no key, identical output otherwise.
  - `write-page --decide`: catch the near-dup TxnError path — when guard refuses and env ready, one `noul` ("genuinely same page?"); verdict attached to the error JSON as `"decision": {"same_page_p": <float>}` before re-raise/emit.
